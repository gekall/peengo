# Peengo

Arkadaşlarla günün 1440 dakikasını doldurma oyunu. Her işediğinde butona bas, o dakika senin renginle boyansın. Aynı dakikayı birden fazla kişi doldurursa renkler karışır.

**Site:** https://gekall.github.io/peengo/

- Kullanıcı adı + şifreyle telefondan ve bilgisayardan aynı profile girilir.
- Kullanıcı adları ve renkler benzersizdir.
- Dakikayı sunucu (Türkiye saati) belirler; geçmişe işaret konamaz.
- Telefonda "Ana ekrana ekle" ile uygulama gibi kullanılır. Adresin sonuna `#bas` eklenirse açıldığı an kayıt atar.

Veriler Supabase'de tutulur. Veritabanı kurulumu: `supabase-kurulum.sql`.
